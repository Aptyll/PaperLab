# Notebook

Paper Lab's research notes. Each note is one Markdown file named `YYYY-MM-DD-short-title.md`, so the folder sorts by date. The first `# ` line is the title. The Notes page in Paper Lab shows them newest first; this README is not shown there.

When Noah sends a thought in the project chat, Claude adds it here as a new file, keeping his words, and it reaches his computer with the next update.

Notes can use headings (`##`), paragraphs, `-` lists, `>` quotes, **bold**, *italics*, `code` and links.
